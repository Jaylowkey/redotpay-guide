Perguntas frequentes

Como recebo o bónus de $5?

Para esta campanha, o utilizador deve entrar pelo nosso link de convite e usar o código jt6mg durante o registo. O bónus de $5 está sujeito às regras, elegibilidade e condições da campanha da RedotPay; esta página não garante o pagamento do bónus.

O bónus de $5 e os 20% de desconto acumulam?

São benefícios diferentes: o bónus está associado à campanha de novos utilizadores e o desconto é aplicado através do código promocional do cartão. A disponibilidade e eventual acumulação devem ser confirmadas no checkout/app no momento da compra.

Posso colocar o código de convite depois?

Não. A RedotPay informa que o código de indicação deve ser inserido durante o registo e não pode ser acrescentado a uma conta já criada.

O código de desconto é o mesmo que o código de convite?

Não. O convite é jt6mg. Os códigos de cartão são PAYGOV20 para virtual e PAYGOP20 para físico, conforme a campanha apresentada.

Os 850 MT são uma taxa da RedotPay?

Não apresente este valor como uma taxa oficial da RedotPay. Nesta página, 850 MT é o valor definido para a operação de recarga/serviço. O preço e as condições devem ser confirmados antes do pagamento.

O pagamento é seguro?

O botão deve encaminhar para o checkout da ZumboPay. Não coloque chaves secretas da API no código do navegador. A integração real deve ser feita no backend.
